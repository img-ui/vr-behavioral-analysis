# VR Behavioral Analysis

Python-based behavioral data analysis of a synthetic XR embodiment and moral decision-making experiment.

## Project Overview

This project explores behavioral data analysis methods using a synthetic dataset inspired by an XR perspective-taking experiment.

Participants are assumed to experience one of two embodiment conditions:

- Sheep embodiment
- Farmer embodiment

After the embodiment phase, participants complete a moral decision-making task in which they choose whether to save the sheep or the farmer.

The project is designed as a portfolio and learning project for behavioral research, cognitive science, HCI, and XR research.

## Planned Analyses

The project will include:

- Data cleaning and preprocessing with Pandas
- Exploratory data analysis
- Data visualization
- Descriptive statistics
- t-tests and ANOVA
- Effect size estimation
- Correlation analysis
- Linear regression
- Logistic regression
- Behavioral gaze metrics

## Example Variables

The synthetic dataset will include variables such as:

- `participant_id`
- `embodiment_condition`
- `decision`
- `decision_time_sec`
- `embodiment_score`
- `presence_score`
- `agency_score`
- `moral_conflict_score`
- `gaze_switches`
- `gaze_time_sheep`
- `gaze_time_farmer`

## Data

The dataset used in this repository is entirely synthetic and contains no real participant data.

It is designed to simulate plausible behavioral patterns for educational and portfolio purposes.
